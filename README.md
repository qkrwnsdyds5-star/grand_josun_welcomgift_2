# JOSUN ÉCLAT (조선 에끌라) 프리미엄 웰컴기프트 프레젠테이션 웹페이지

그랜드 조선 호텔(GRAND JOSUN)의 환대 헤리티지와 신세계푸드 베키아에누보(Vecchia & Nuovo)의 유러피언 파티세리가 결합된 신규 웰컴기프트 브랜드 **JOSUN ÉCLAT**의 디지털 브로슈어 및 대시보드형 프레젠테이션 웹사이트입니다.

객실에 비치된 웰컴기프트 상자 또는 브로슈어의 QR코드를 스캔하여 접속하며, 첫 화면의 **'디지털 가이드 바로가기' 대시보드 허브**를 통해 **'소개', '기프트', '스토리', '영감', '안내' 5대 바로가기**를 한눈에 둘러보고 원하는 페이지로 즉각 이동할 수 있습니다. 상단 헤더 중앙의 **'BUSAN / JEJU / KIDS' 스위처**를 통해 3대 독립 컬렉션을 자유롭게 오갈 수 있습니다.

---

## 1. 최신 v3.1 UI 업데이트 핵심 변경사항

### ① 첫 화면: '디지털 가이드 바로가기' 단독 집중형 대시보드
- 첫 화면(Slide 0)을 핵심 5대 네비게이션 버튼에 온전히 집중하도록 정돈하였습니다:
  - **'소개' (Welcome & Hero)**: 에디션 웰컴 무드와 패키지 브로슈어 안내 페이지로 이동
  - **'기프트' (Signature Gifts)**: 지역별 디저트 세트 및 키즈 아틀리에 키트 상세 페이지로 이동
  - **'스토리' (Heritage & Story)**: 100년 전통 조선호텔과 베키아에누보 파티세리 철학 페이지로 이동
  - **'영감' (Local Inspiration)**: 바다, 오름, 동심에서 길어 올린 모티브 페이지로 이동
  - **'안내' (Concierge & Info)**: 호텔 위치 및 컨시어지 서비스 가이드 페이지로 이동
- 상단 3개(소개, 기프트, 스토리) + 하단 2개(영감, 안내)로 정갈하게 대칭을 이루는 6컬럼 그리드 레이아웃 적용.
- 불필요한 에디션 선택 박스 및 하단 중복 카드를 과감히 정리하여 Quiet Luxury의 미니멀한 감성을 극대화.

### ② 상단 헤더: 'BUSAN / JEJU / KIDS' 정중앙 정렬
- 상단 헤더 내 '대시보드' 버튼을 삭제하여 시각적 군더더기를 없앴습니다.
- **`BUSAN / JEJU / KIDS` 카테고리 스위처를 상단 헤더 정중앙(`center`)에 완벽하게 정렬** 배치하였습니다.
- 좌측 브랜드 로고 `JOSUN ÉCLAT`를 클릭하면 언제든 첫 대시보드 화면으로 즉시 복귀합니다.

### ③ 부산, 제주, 키즈 3대 웰컴기프트 완전 독립 분리
- 부산, 제주 성인용 기프트와 키즈 웰컴기프트의 슬라이드 흐름을 완전히 분리하였습니다:
  - **부산 (GRAND JOSUN BUSAN)**: 해운대 바다를 품은 3종 시안 (사브레, 쇼콜라, 마스터피스) 단독 제공 (키즈 내용 배제)
  - **제주 (GRAND JOSUN JEJU)**: 한라산과 곶자왈을 품은 2종 시안 (한라 오름 쇼콜라, 마스터피스) 단독 제공 (키즈 내용 배제)
  - **키즈 (GRAND JOSUN KIDS)**: 쿠키 아틀리에 키트 상세, 4-Step DIY 인터랙티브 스텝퍼, 종이 브로슈어, 알레르기 안내 아코디언 단독 제공

### ④ 기프트 페이지(Slide 2) 레이아웃 수평 정중앙 정렬
- 부산, 제주(성인 시안 카드) 및 키즈(아틀리에 키트, 4-Step DIY 스텝퍼, 브로슈어 카드, 식품안전 아코디언) 전체 요소가 좌측으로 쏠리지 않고 화면 중앙(`margin: 0 auto` 및 Flexbox Column Center)에 완벽하게 정렬되도록 CSS 레이아웃 구조를 보정.

### ⑤ 4개 국어(KO, EN, ZH, JA) 완벽 지원
- 한국어, 영어, 중국어, 일본어 전 언어에 걸쳐 대시보드 5개 버튼, 브랜드 스토리, 기프트 상세 안내까지 정교한 다국어 번역 제공.

## 4. 로컬 실행 방법

외부 빌드 툴 없이 브라우저에서 바로 구동됩니다:

1. **브라우저 직접 실행**:
   `index.html` 파일을 더블클릭하여 바로 열 수 있습니다.

2. **로컬 웹서버 실행**:
   ```bash
   npx serve .
   # 또는
   python -m http.server 8080
   ```
   브라우저에서 `http://localhost:8080` 접속:
   - 부산 대시보드: `http://localhost:8080/?location=busan&lang=ko`
   - 제주 대시보드: `http://localhost:8080/?location=jeju&lang=ko`
   - 키즈 대시보드: `http://localhost:8080/?location=kids&lang=ko`
